# Superpowers

Local copy of the [obra/superpowers](https://github.com/obra/superpowers) skill pack (MIT, copyright Jesse Vincent). Pin is in `PIN`.

These are markdown skills the agent reads with `read_file`. They are not a plugin marketplace install and they do not spawn a local MCP server with host permissions.

Update by checking out that commit's `skills/*/SKILL.md` files. Do not add a second copy under Cursor's plugin marketplace on top of this tree.
